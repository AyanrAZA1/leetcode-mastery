# 🧠 LeetCode Mastery

A structured, revision-friendly repository for mastering:

- Data Structures & Algorithms
- Algorithmic Patterns
- SQL & Database Problems
- Interview Preparation
- Company-wise Questions
- Problem-solving patterns and revision notes

---

## 📚 Repository Structure

| Section | Purpose |
|---|---|
| `01-DSA` | Core DSA problems |
| `02-Algorithms` | Algorithm techniques |
| `03-SQL` | SQL problems |
| `04-Data-Structures` | Data-structure focused problems |
| `05-Patterns` | Reusable problem-solving patterns |
| `06-Company-Wise` | Company-specific interview problems |
| `07-Revision` | Important problems and mistakes |
| `08-Templates` | Reusable coding templates |
| `09-Statistics` | Progress and statistics |

## 🎯 Difficulty

Every problem is classified as:

- 🟢 Easy
- 🟡 Medium
- 🔴 Hard

---

## 📝 Problem Format

Every problem should contain:

- LeetCode problem number
- Problem name
- Difficulty
- Topics
- Pattern
- Problem statement/reference
- Approach
- Complexity
- Solution
- Key insight
- Revision notes
